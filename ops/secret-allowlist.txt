# هر سطر غیرکامنت، یک SHA-256 از «مسیر فایل» + TAB + «متن همان خط» است.
#
# چون مسیر داخل هش است، هر ورودی دقیقاً یک خط از یک فایل مشخص را آزاد
# می‌کند — نه یک پوشه، نه یک پسوند، نه یک الگو. اگر همان خط عوض شود، یا
# راز واقعی جای دیگری از همان فایل بنشیند، هش نمی‌خواند و Push متوقف
# می‌شود. قاعده عمومی اسکن راز دست‌نخورده می‌ماند.
#
# اینجا عمداً بیرون از ops/hooks/ است: بند ۳ هوک برای هر فایل زیر
# ops/hooks/ بیت اجرا می‌خواهد، و install-hooks.sh هرچه آنجاست را به
# .git/hooks/ کپی می‌کند — هیچ‌کدام برای یک فایل داده درست نیست.
#
# فقط برای نمونه‌های مستنداتی Vendor و داده‌های ساختگیِ تست. راز واقعی هرگز اینجا
# نمی‌آید — راز واقعی Revoke می‌شود، نه Allow.
#
# بازتولید پس از به‌روزرسانی Skillها (PATTERNS از خود pre-push):
