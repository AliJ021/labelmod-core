# پروب زمان رویداد اسکن HID — شاهد PR182

`probe.spec.ts.txt` همان پروب موقتی است که اجرا شد (پسوند `.txt` تا Playwright، eslint و tsc آن را
اجرا یا بررسی نکنند) و `output.txt` خروجی واقعی همان اجرا. هر چهار حالت فقط شرط «یک اسکن ثبت شد» را
دارند؛ نتیجه در خط چاپ‌شده است، نه در pass/fail.

- **P1 — کنترل منفی:** مسیر ساختگی پیش از اصلاح (ساخت هر رویداد پس از ارسال قبلی) + توقف ۶۰ms پس
  از کلید ۱ → `2345678901234567`، همان شکست CI در PR180 (webkit-dark-768).
- **P2:** همان مسیر بی توقف → کامل.
- **P3 — اصلاح:** ساخت همهٔ رویدادها پیش از ارسال + همان توقف → کامل (فاصله 0.2ms).
- **P4:** ورودی واقعی CDP + توقف ۱۰۰ms main thread در یک keydown handler → کامل (فاصله 0.3ms).

حدود: فقط Chromium اجرا شد؛ WebKit بومی محلی در دسترس نبود و رفتار زمان رویداد ورودی واقعی آن سنجیده
نشده است. پذیرش پسوندِ اسکن کندِ واقعی (فاصلهٔ بیش از ۵۰ms میان کلیدهای اسکنر) محدودیت باز و جدای
محصول است و این تغییرِ فقط‌آزمون آن را حل نمی‌کند.
