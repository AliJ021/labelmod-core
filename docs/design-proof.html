پوسته شیشه‌ای لیبل مد

Liquid Glass، ناحیه‌بندی‌شده. شیشه کامل روی داشبورد، سطح مات و پرتضاد روی صندوق — و توکن‌هایی که این تفکیک را از روز اول ممکن می‌کنند.

حالت عملکرد را بزنید — شیشه کاملاً حذف می‌شود
۱

چرا همه‌جا شیشه نه

رابطی که همه‌چیزش شیشه است، Liquid Glass نیست — بدفهمی آن است. راهنمای خود اپل می‌گوید شیشه به لایه کنترلی تعلق دارد، نه به محتوا، و شیشه روی شیشه هرگز.

✓ داشبورد — شیشه کامل

خوانده می‌شود، نه عمل

روی دسکتاپ، در آرامش، چند بار در روز. عمق و شفافیت اینجا همان حس «اپ بانکی» را می‌سازد که سند خواسته بود — بدون اینکه هزینه‌ای بدهد.

✗ صندوق — تضاد رنگی

نور فروشگاه

صندوق‌دار زیر مهتابی و گاهی آفتاب کنار ویترین کار می‌کند و باید عدد قیمت را در کسری از ثانیه بخواند. سطح نیمه‌شفاف مستقیماً با این می‌جنگد.

تکنیک

آنچه «شیشه» را از «تاری» جدا می‌کند، بلور نیست — بازتاب لبه و اشباع رنگ است.

.glass {
  background: var(--surface-glass);
  backdrop-filter: blur(var(--glass-blur)) saturate(180%);
  /* اشباع، رنگ پشت را زنده نگه می‌دارد — بدون آن شیشه گِلی می‌شود */
  box-shadow:
    var(--glass-shadow),
    inset 0 1px 0 var(--glass-rim),      /* لبه بالا: نور */
    inset 0 -1px 0 var(--glass-rim-2);   /* لبه پایین: سایه */
}

/* بازتاب ویژه — رینگ گرادیانی فقط روی مرز */
.glass::after {
  content: ""; position: absolute; inset: 0; padding: 1px;
  border-radius: inherit; pointer-events: none;
  background: linear-gradient(140deg,
      var(--glass-rim) 0%, transparent 34%,
      transparent 64%, var(--glass-rim) 100%);
  mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  mask-composite: exclude;  /* فقط رینگ می‌ماند، وسط خالی */
}
شکست نور واقعی (feDisplacementMap) عمداً استفاده نشده. پشتیبانی مرورگری‌اش ناقص است — روی سافاری اصلاً کار نمی‌کند و روی موبایل گران است. ترکیب بالا در همه‌جا یکسان رندر می‌شود و ۹۰٪ همان حس را می‌دهد. اگر روزی پشتیبانی عمومی شد، به‌صورت @supports اضافه می‌شود بدون تغییر توکن‌ها.
سه قاعده سخت که در کد اجبار می‌شوند: شیشه روی شیشه ممنوع · متن روی سطح شیشه‌ای حداقل ۴٫۵:۱ تضاد، سنجیده با بدترین محتوای پشتش · انیمیشن فقط روی transform و opacity، هرگز روی width و top.

بودجه عملکرد صندوق: افزودن قلم به سبد زیر ۱۰۰ میلی‌ثانیه روی ضعیف‌ترین دستگاه هدف. هر افکتی که این را بشکند حذف می‌شود — بدون بحث.

پالت با اسکریپت اعتبارسنجی بررسی شده: رنگ نمودار روی هر دو سطح ≥۳:۱ تضاد دارد (پله تیره‌تر #B0801F در تم روشن)، و هشدار در برابر خطا ΔE ۱۸٫۷ برای دید عادی و ۱۰٫۷ در کوررنگی — هر دو با آیکون و برچسب می‌آیند، نه فقط رنگ. تم تیره جداگانه انتخاب شده، نه معکوسِ خودکارِ تم روشن.
