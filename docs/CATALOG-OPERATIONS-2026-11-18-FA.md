# فهرست کالا، اصلاح نام و انتخاب گروهی تنوع‌ها

## رفتار

- فهرست «کالا و قیمت» هر بار ۱۰۰ کالا می‌خواند. «صفحهٔ بعد»، «صفحهٔ قبل» و «صفحهٔ اول» ادامهٔ فهرست را در دسترس می‌گذارند؛ ۱۱۴ کالا یعنی ۱۰۰ و سپس ۱۴ ردیف.
- جست‌وجو، دسته و بایگانی در سرور اعمال می‌شوند. تغییر فیلتر از صفحهٔ اول شروع می‌کند؛ شمارهٔ صفحه در نشانی می‌ماند و برگشت از جزئیات و Reload آن را حفظ می‌کنند.
- شمار کنار صفحه فقط شمار همان صفحه است؛ کارت «کالای فعال» شمار کل فعال‌ها را دارد. انتخاب کالا برای چاپ گروهی بین صفحه‌ها حفظ می‌شود؛ «انتخاب همهٔ این صفحه» فقط ردیف‌های حاضر را انتخاب می‌کند.
- در جزئیات کالا، «ویرایش نام کالا» نام داخلی را اصلاح می‌کند. نام سایت، کد، SKU، بارکد، قیمت، وضعیت و سایر مشخصات تغییر نمی‌کنند. نام داخلی تازه در لیبل‌های بعدی استفاده می‌شود.
- دو ویرایش متفاوت با یک نام اولیه، همدیگر را بی‌خبر بازنویسی نمی‌کنند؛ دومی خطای تعارض می‌گیرد. تغییر نام از تابع موجود کالا می‌گذرد و در حسابرسی ثبت می‌شود.
- «انتخاب همهٔ تنوع‌ها» همهٔ ردیف‌های همان کالا را انتخاب می‌کند و با برداشتن تیک، انتخاب‌ها پاک می‌شوند. انتخاب به‌تنهایی قیمت یا موجودی را تغییر نمی‌دهد.
- حذف دائمی کالا در برنامه مسیر ندارد؛ بایگانی، سابقه و ارجاع اسناد را حفظ می‌کند. این تغییر قابلیت حذف یا بازنویسی اسناد اضافه نمی‌کند.

## سازگاری و استقرار

هیچ فایل مهاجرت، Seed یا تغییر مستقیم موجودی در این تغییر نیست. API و وب باید از یک نسخه ساخته شوند؛ وب تازه به پاسخ صفحه‌بندی API نیاز دارد. `GET /products` همچنان آرایهٔ `products` دارد و دو فیلد `page` و `hasMore` افزوده شده‌اند. سقف ۵۰۰ ردیف برای هر درخواست حفظ است و یک سطر اضافه فقط برای تشخیص صفحهٔ بعد خوانده می‌شود.

`WORKER_INTERVAL_MS=1000` یعنی فاصلهٔ بررسی یک ثانیه؛ این تنظیم تضمین همگام‌شدن زیر یک ثانیه یا جلوگیری قطعی از رقابت خرید درگاه با صندوق نیست. PR #229 مربوط به نگه‌داشت پیش از پرداخت، به تصمیم مالک بدون ادغام بسته شد؛ رزروهای از قبل موجودِ پرداخت در محل از این تصمیم حذف نشده‌اند.

## پذیرش

آزمون API روی دیتابیس یک‌بارمصرف: ۱۱۴ کالای فعال، بایگانی، دسته، صفحهٔ خالی، مرز دقیق و سقف ۵۰۰؛ ویرایش نام با حفظ همهٔ فیلدهای دیگر و تنوع‌ها و قیمت‌ها، تکرار، تعارض هم‌زمان، ورودی نامعتبر، مجوز و حسابرسی.

آزمون مرورگر: صفحهٔ دوم، جزئیات و بازگشت، Reload و Back، فیلترها، انتخاب چاپ بین صفحه‌ها، حالت خطا، ویرایش/انصراف نام و انتخاب همهٔ تنوع‌ها. ماتریس canonical مرورگر همچنان هر دو موتور و هر دو تم و شش عرض است؛ نتیجهٔ CI همان commit مرجع پذیرش فنی است. نصب تولید و مشاهدهٔ واقعی کاربر جداگانه تأیید می‌شوند.
