### اصلاحات خط مبنا

- فایل مجوز فونت بایت‌به‌بایت سنجیده می‌شود؛ برای جلوگیری از تبدیل LF به CRLF در ویندوز، `.gitattributes` آن را از تبدیل متن خارج می‌کند.
- آزمون پارچه جداکنندهٔ مسیر سیستم‌عامل را قبل از مقایسهٔ همان فهرست دقیق یکسان می‌کند؛ انتظار آزمون کم نشده است.
- Dialog امکان تعیین صریح عنصر بازگشت فوکوس را از hook موجود عبور می‌دهد؛ UI Kit بازکنندهٔ Dialog و Sheet را ثبت می‌کند تا WebKit هم فوکوس را بازگرداند. کنترل Sheet به آزمون موجود اضافه شد.
- آزمون مجوز جزئی تنظیمات پیش از ناوبری کامل، پایان پاسخ پایانه‌ها را بررسی می‌کند. هیچ خطای مرورگر پنهان و هیچ کنترل مجوزی حذف نشده است.
