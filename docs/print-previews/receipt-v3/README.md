# فاکتور — بازبینی سوم طراحی

نسخهٔ سوم براساس بازخورد مالک، ساختار خواندن را اصلاح می‌کند: نام هر کالا تمام‌عرض است و تعداد، قیمت واحد و جمع در ستون‌های مشخص و هم‌راستا قرار می‌گیرند. تخفیف قلم برچسب مستقل دارد. مشخصات، اقلام و خلاصهٔ حساب قاب مشترک دارند؛ مبلغ قابل پرداخت نقطهٔ اصلی نگاه است و لوگو با سربرگ تناسب دارد.

- [رسید ۸۰ میلی‌متر](standard-print.png)
- [پیش‌فاکتور پیش از نهایی‌سازی](proforma-print.png)

هر دو تصویر از `invoicePage` واقعی با دادهٔ ساختگی، در رسانهٔ چاپ و پهنای ۸۰ میلی‌متر تولید شده‌اند. پهنای محتوای چاپ ۷۲ میلی‌متر است. ۶ سناریو (معمولی، پیش‌فاکتور با مرجع بلند، تخفیف کامل، پرداخت جزئی، نام بلند و ۳۲ قلم) در چاپ و موبایل، مجموعاً ۱۲ بررسی بدون سرریز عرض/سلول یا رقم فارسی/عربی گذشتند. ۳۰ تست قالب و لوگو نیز موفق است. اعداد لاتین، تاریخ جلالی و محاسبات دقیق حفظ شده‌اند. این شواهد جای تأیید ظاهر توسط مالک یا چاپ کاغذ واقعی را نمی‌گیرند.

بازتولید از ریشهٔ مخزن:

```sh
node --experimental-strip-types ops/render-receipts.ts ./evidence/receipt-v3
```

Playwright Chromium لازم است؛ روی ویندوز با Edge نصب‌شده، `PLAYWRIGHT_EDGE=1` را تنظیم کنید. خروجی شامل HTML، PNG و `checks.json` است.
