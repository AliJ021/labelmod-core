# فاکتور — بازبینی دوم طراحی

بازخورد مالک: اقلام بی‌قاب‌اند و ظاهر هنوز یکپارچگی و کیفیت کافی ندارد.

مشکلات نسخهٔ قبل: وزن زیاد و تقریباً یکسان متن‌ها، خط‌های ضخیم و خط‌چین کنار کادرهای گرد، ردیف‌های بدون قاب، و خلاصهٔ حساب پراکنده. در نسخهٔ دوم مشخصات، اقلام و حساب با زبان مشترک قاب‌بندی شدند. عنوان بخش از برچسب ستون جداست، هر قلم فاصله و جداکنندهٔ مشخص دارد، و دریافتی/مانده/وضعیت تسویه داخل خلاصهٔ حساب می‌مانند. پس‌زمینهٔ ملایم عنوان‌ها فقط برای نمایش است؛ چاپ حرارتی سیاه‌وسفید می‌ماند.

- [رسید با کادر اقلام](standard-print.png)
- [پیش‌فاکتور](proforma-print.png)

اعداد انگلیسی، تاریخ جلالی، مبالغ دقیق، سیاست نمایش سایز و مسیرهای چاپ/پرداخت تغییری نکرده‌اند. این تغییر صرفاً قالب و فاصله‌گذاری است؛ تأیید زیبایی از طرف مالک ادعا نشده است.

رندرها دادهٔ ساختگی دارند. ۶ سناریو (معمولی، پیش‌فاکتور با مرجع بلند، تخفیف کامل، پرداخت جزئی، نام‌های بلند و ۳۲ قلم) در دو رسانهٔ چاپ و موبایل، مجموعاً ۱۲ بررسی بدون سرریز سلول/عرض یا رقم فارسی/عربی، موفق شدند. ۲۶ تست قالب و بررسی نوع API نیز موفق است. چاپ واقعی هنوز باید روی دستگاه پذیرش شود.

بازتولید از ریشهٔ مخزن:

```sh
node --experimental-strip-types ops/render-receipts.ts
```

Playwright Chromium لازم است؛ در ویندوز با Edge نصب‌شده متغیر `PLAYWRIGHT_EDGE=1` قابل استفاده است. ابزار، HTML و PNG و گزارش هندسه را در مسیر خروجی می‌سازد؛ مسیر دلخواه را به‌عنوان آرگومان اول بدهید.
