# چاپ بارکد بدون قیمت و نام سه‌خطی

این تغییر بر پایهٔ main در `c3a9680d194b48a1bcae2f816ce61ec747943161` است؛ اصلاحات PR 223 را تکرار نمی‌کند و شامل رزرو موجودی PR 229 نیست. هیچ مهاجرت، تغییر قیمت، موجودی یا افزونهٔ ووکامرس ندارد.

## استفاده

در «کالا و قیمت ← چاپ لیبل بارکد»، کالاهای موردنظر را به فهرست چاپ گروهی اضافه کنید. در همان فهرست «چاپ بدون قیمت» را روشن و پیش‌نمایش را بسازید. این گزینه در پنل چاپ داخل هر کالا نیز هست. در حالت روشن، عدد قیمت، «تومان» و نشان «بدون قیمت» از خود لیبل حذف می‌شوند؛ قیمت ثبت‌شدهٔ کالا تغییری نمی‌کند.

انتخاب برای همان پنل است و در تنظیمات چاپگر ذخیره نمی‌شود. چاپ گروهی گزینهٔ مستقل و قابل مشاهده دارد. تغییر گزینه پیش‌نمایش قبلی را باطل می‌کند؛ پس از بارگذاری دوباره حالت «با قیمت» برمی‌گردد. رول تک‌ستونه، چندستونه و A4 پشتیبانی می‌شوند.

نام بلند ابتدا فضای بیشتر تا سه خط می‌گیرد و در صورت نیاز قلم شرح تا ۱٫۳ میلی‌متر کوچک می‌شود. میله‌ها حداقل ۵ میلی‌متر می‌مانند و مقدار بارکد تغییر نمی‌کند. متن ناممکن روی لیبل بسیار کوچک همچنان با پیام روشن رد می‌شود؛ به جای چاپ ناقص، باید اندازهٔ بزرگ‌تری انتخاب شود. خوانایی فیزیکی قلم کوچک به چاپگر وابسته است.

## شواهد محلی

- ۵۵ آزمون سازندهٔ لیبل، هندسه، مقدار بارکد و حذف قیمت پاس شدند.
- ۵۵۶ آزمون وب پاس شدند؛ روی Windows برای فرمان `python3` از Python 3.12 نصب‌شده استفاده شد.
- lint و typecheck API و وب و build وب پاس شدند.
- ۶۰ سناریوی قبلی چاپ در Edge/Chromium، روشن ۱۴۴۰ و تیره ۳۷۵ پاس شدند؛ ۶ اجرای سناریوهای جدید حذف قیمت، متن بلند، تغییر پیش‌نمایش و بازنشانی پس از reload نیز پاس شدند.
- آزمون API با نقش مالک و محدود، SQL، WebKit و ساخت ایمیج‌ها در CI مخزن اجرا می‌شوند؛ نتیجهٔ همان commit مرجع است.
- چاپگر فیزیکی و سرور اصلی از این محیط به‌روزرسانی یا تأیید نشده‌اند.

## انتشار

اگر سرور از قبل دقیقاً روی مبنای بالا و مهاجرت‌های آن است، این اصلاح فقط بازسازی و راه‌اندازی API و وب می‌خواهد. اگر سرور قدیمی‌تر است، تفاوت مهاجرت‌های آن تا commit منتشرشده را طبق [راهنمای استقرار، بخش ۸](DEPLOYMENT.md#۸-بهروزرسانی) بررسی کنید؛ این اصلاح به‌تنهایی مجوز پرش از مهاجرت‌های قبلی نیست. روی دادهٔ موجود `seed` اجرا نمی‌شود.

پس از انتشار، صفحه را با Ctrl+Shift+R تازه کنید؛ ابتدا یک ردیف بدون قیمت چاپ و همان بارکد را اسکن کنید، سپس تعداد کامل را چاپ کنید. مقیاس ۱۰۰٪، بدون Fit و بدون سربرگ/پابرگ؛ در رول چندستونه اندازهٔ کاغذ برابر کل ردیف است. تنظیم اندازه و فاصلهٔ قبلی چاپگر حفظ می‌شود.
