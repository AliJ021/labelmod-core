## ولی همان اندازه‌گیری یک نقص واقعی پیدا کرد — FND-014

**اسکرول افقی کل صفحه، ۱۰۵ پیکسل، روی هر نه صفحه — و فقط روی ۷۶۸px**،
که تبلت عمودی است: همان دستگاهی که ADR-002 برای صندوق هدف گرفته.

علت یک **شکاف Breakpoint** بود:

```
.zones  overflow-x: auto   فقط در  @media (max-width: 560px)
چیدمان دسکتاپ              از      @media (min-width: 900px)
                    ⇒ بازهٔ ۵۶۱ تا ۸۹۹ هیچ قاعده‌ای نداشت
```

نُه دکمهٔ نوار بخش‌ها جا نمی‌شدند، و چون `.zones` یک آیتم Flex با
`min-width: auto` است **کوچک نمی‌شود** — پس به‌جای اسکرول خودش، **کل
صفحه** اسکرول می‌خورد.

⚠️ کامنت خودِ همان بلوک می‌گفت «اسکرول افقی فقط برای نوار بخش‌ها، نه
برای کل صفحه» — نیت درست بود، دامنه‌اش کم بود.

و یک مورد دوم: `.row` روی ۳۲۰px نمی‌شکست و «کالا و قیمت» ۲۳ پیکسل
بیرون می‌زد.

| ۴۲۸ | ۰ | ۰ |
| **۷۶۸** | **۱۰۵px روی هر نه صفحه** | **۰** |
| ۱۰۲۴ | ۰ | ۰ |

پس از اصلاح: **صفر اسکرول افقی روی هر ۶۳ ترکیب**، و چشمی هم بررسی شد.

### اصلاح

```css
@media (max-width: 899px) {
  .zones, .tools { min-width: 0; overflow-x: auto; }
}
@media (max-width: 560px) { .row { flex-wrap: wrap; } }
```

⚠️ **`min-width: 0` قلب اصلاح است**: بی آن `overflow-x` روی یک آیتم Flex
بی‌اثر است، چون آیتم هرگز کوچک‌تر از محتوایش نمی‌شود.

⚠️ `.row { flex-wrap }` فقط زیر ۵۶۰px — بالاتر، ردیف‌ها جا می‌شوند و
شکستنشان چیدمان را بی‌دلیل عوض می‌کرد.

### ضد‌بازگشت

`apps/web/test/direction.test.ts` — پنج ادعا، از جمله یکی که شکاف
Breakpoint را **عددی** می‌سنجد: بیشترین `max-width` مهارِ `.zones` باید
≥ کمترین `min-width` دسکتاپ منهای یک باشد.

```
بدون اصلاح  ✗ ۲ شکست (شکاف Breakpoint · min-width: 0)
با اصلاح    ✓ ۲۰۴ پاس
```

⚠️ این تست **جای مرورگر را نمی‌گیرد** و ادعا نمی‌کند که می‌گیرد.
Playwright عمداً وابستگی این پروژه نیست؛ از نسخهٔ سراسری محیط برای
ممیزی استفاده شد و به مخزن اضافه نشد.

## یادداشت فونت

`document.fonts.size === 0` — فونت Vazirmatn از Google Fonts در محیط
ممیزی بارگذاری **نشد**، یعنی کل ممیزی در شرایط «نبودِ اینترنت» اجرا شد
که پرامپت می‌پرسد.

پاسخ مشاهده‌شده: **Fallback کاملاً خواناست** — فارسی درست، راست‌چین
درست، چیدمان سالم. **نقص نیست.** ولی یک وابستگی به شبکهٔ خارجی در مسیر
Render هست، و همین فروشگاه است که برایش «صف آفلاین» فکر شده. Self-host
کردن دو فونت یک **پیشنهاد** است.
