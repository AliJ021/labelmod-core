# مدل تهدید و نتیجهٔ آزمون‌های امنیتی

دامنه: مخزن `labelmod-core` — API، رابط وب، Worker، افزونهٔ ووکامرس،
دیتابیس. همهٔ آزمون‌ها روی **نمونهٔ ایزوله با دادهٔ مصنوعی** اجرا شدند؛
هیچ آزمون تهاجمی روی سایت زنده یا سرویس ثالث انجام **نشد** (بند ۱۰).

## مرزهای اعتماد

```
۱. مرورگر پرسنل        →  API        کوکی نشست SameSite=Strict + CSRF
۲. سایت ووکامرس        →  API        کلید API، بی CSRF (عمدی)
۳. مشتری (ناشناس)      →  /i/<توکن>  توکن فاکتور، بی نشست
۴. Worker              →  API/DB     بی درخواست HTTP، پس بی ip/device
۵. اپراتور سرور (SSH)  →  DB         **بیرون از مدل** — دسترسی کامل
۶. نقش برنامه          →  DB         از مهاجرت ۰۵۰ محدودشدنی
```

## دارایی‌ها به ترتیب ارزش

۱. **دفتر کل و اسناد مالی** — اگر خراب شود، اظهارنامه و سود غلط می‌شود.
۲. **ارزش و تعداد موجودی** — پول در قفسه.
۳. **دفتر حسابرسی** — تنها چیزی که می‌گوید چه کسی چه کرد.
۴. رمز و PIN پرسنل، راز دستگاه، کلید API، کلید پیامک.
۵. داده مشتری (PII، رضایت بازاریابی، اندازه بدن).

## عامل‌های تهدید و توانشان

| عامل | توان | مهم‌ترین هدف |
|---|---|---|
| صندوق‌دار | نشست کامل، نقش محدود | بازپرداخت جعلی، تخفیف بی‌مجوز، پنهان‌کردن کسری کشو |
| پرسنل با PIN | نشست **ارتقانیافته** | همان‌ها، ولی `pin_forbidden_operations` بسته |
| مهاجم شبکه | ترافیک | نشست، توکن فاکتور |
| سایت ربوده‌شده | کلید API | سفارش جعلی، قیمت جعلی |
| مشتری | توکن فاکتور خودش | دیدن فاکتور دیگری، تغییر قیمت سفارش |
| **فرد درون‌سازمانی با SSH** | دسترسی کامل DB | بازنویسی تاریخچه، جعل دلیل و مقدار قبلی |

## تهدیدهای پوشش‌نداده — صریح

۱. **اپراتور SSH** بیرون از مدل است و بودنش پذیرفته. دفاعش «لنگر
   انداختن» بند ۳ SECURITY.md است، و همین ممیزی نشان داد آن لنگر برای
   `before` و `reason` **کار نمی‌کرد** (FND-017، اصلاح شد).
   ⚠️ و لنگر هنوز یک **رویهٔ عملیاتی** است، نه کد: کسی باید هش شبانه را
   بیرون از سرور نگه دارد.

۲. **امضای Webhook ورودی** وجود ندارد چون مسیر ورودی Push هنوز ساخته
   نشده (ADR-007). مسیر موجود `/web/orders` با کلید API محافظت می‌شود که
   برای امروز کافی است ولی Timestamp/Nonce ندارد.

۳. **SSRF** فقط طراحی شده (بند ۶ ADR-007).

۴. **هشدار بیرونی** نیست: هیچ‌کدام از ثابت‌های امنیتی بالا کسی را خبر
   نمی‌کنند؛ `deploy.sh status` دستی است.

۵. **آزمون تهاجمی روی سایت زنده** انجام نشد — ممنوع بود و نباید بشود.
