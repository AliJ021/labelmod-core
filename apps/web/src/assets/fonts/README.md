# Local fonts

Vazirmatn v33.003: variable upright weights 100–900 (UI uses 300–800).
IBM Plex Mono 2.5.0: upright 400, 500, 600, 700; source commit 78cd4223d8de9fcb78cba84eadecb269c56093c5.

Both fonts use SIL Open Font License 1.1; complete licenses are included alongside the files. Unmodified upstream WOFF2 files are imported by Vite, emitted with content hashes and served from the application origin. sources.json records exact source URLs, sizes and SHA-256 checksums. No remote font stylesheet or runtime download is required.
